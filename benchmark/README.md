# scLR-multi benchmark analyses

This directory contains the scripts, commands, and configuration files used for the benchmarking and comparative analyses reported in the associated scLR-multi manuscript.

The analysis workflow consists of three main stages:

1. Long-read sequencing data were processed using the scLR-multi Nextflow pipeline.
2. Matched short-read datasets were processed using platform-specific workflows. The commands, parameters, and custom scripts used for short-read processing are provided in `short_read/`.
3. Long-read outputs and matched short-read datasets were used for the downstream benchmarking and comparative analyses provided in `analysis/` and `short_long_comparison/`.

Raw long-read and matched short-read sequencing data are deposited in the European Nucleotide Archive (ENA). Accession numbers are provided in the main repository README and in the associated manuscript.

Large intermediate files and analysis outputs are not stored in this repository.

The code in this directory reproduces analyses performed for the benchmark manuscript and is not part of the general-purpose scLR-multi Nextflow workflow.

| `differential_expression.py` | Transcript-level differential expression between NIH-3T3 subclusters | Downsampled isoform matrices | Differential-expression results | TODO |

The scripts should reproduce the analysis parameters and thresholds described in the manuscript, including:

- feature detection in at least 15 nuclei;
- species assignment at ≥80% of counts;
- cell QC thresholds reported in the Methods;
- Scrublet doublet removal;
- normalization to 10,000 counts per nucleus;
- HVG selection and Harmony batch correction;
- KNN with k=15;
- the six Leiden resolutions tested in the manuscript;
- silhouette-based selection of clustering resolution;
- cell-cycle scoring and phase-assignment thresholds;
- three nucleus-sampling replicates and three sequencing-depth downsampling replicates;
- sequencing depths of 3,000, 2,000, 1,000, 500, and 100 UMIs/nucleus;
- gene- and transcript-level analyses where applicable.

Random seeds used for the manuscript analyses should be explicitly recorded.

## `short_long_comparison/`

Scripts used for direct comparison of matched short- and long-read sequencing data.

| Script | Analysis | Main input | Main output | Status |
| --- | --- | --- | --- | --- |
| `match_barcodes.py` | Identification of nuclei represented in both sequencing modalities | Short- and long-read cell barcodes | Matched barcode lists/matrices | TODO |
| `compare_gene_counts.py` | Gene-level short- versus long-read comparison | Matched gene-count matrices | Expression correlations, gene overlaps, and plots | TODO |

The analysis should reproduce the procedure described in the manuscript:

- retain nuclei with matching barcodes between modalities;
- perform ArgenTag barcode translation where required;
- remove genes with zero total counts;
- aggregate raw counts across matched nuclei;
- normalize expression to CPM;
- apply log2(CPM + 1) transformation;
- calculate Pearson and Spearman correlations for shared genes and all detected genes; and
- calculate and visualize gene-detection overlap.

## Requirements for deposited scripts

Before publication, each script should:

1. contain a short description of its purpose;
2. document required inputs and generated outputs;
3. expose input/output paths rather than contain CRG-specific absolute paths;
4. record important analysis parameters;
5. document required software/package versions;
6. use and document the random seed used for the manuscript where stochastic procedures are involved; and
7. provide an example command where appropriate.

The `Status` entries above should be changed from `TODO` to `DONE` as the corresponding scripts and commands are added. Proposed filenames can be changed to match the actual analysis code.
